# 训练流程验证记录

检查日期：2026-10-25。环境：Windows、Python 3.11、PyTorch 2.8.0+cu126、RTX 4070 12GB。

## 本次发现与修复

| 位置 | 问题与处理 |
| --- | --- |
| `model_zoo/TokenMixer.py` | 共享层已改名为 `num_tokens/ffn_expansion`，调用方仍使用 `num_token/expand`，导致构造报错；更新调用参数名。 |
| `unirank/pytorch/models/rank_model.py` | BF16 Sigmoid 会在 logit=6.25 时将概率舍入为 1；负标签 BCE=100、梯度为 0。改为先将 logits 转 FP32 再计算 Sigmoid，保留既有概率和 BCE 接口；测试验证梯度恢复。 |
| `model_zoo/LONGER_RankMixer.py` | 组合编码器缺少位置表长度、分组、query_size、输入形状的检查；增加边界检查，避免非法窗口广播或深层报错。 |
| `model_zoo/RankMixer.py`、`per_token_ffn.py` | 增加 MoE 层数、尺寸、route 名称和输入形状检查，避免零层除零和误用路由。 |
| `config/model_config.yaml` | 新增显式 Dense 对照；现有主实验保留四专家 MoE，NoMixer 保留零交互层。 |
| `README.md`、`tests/test_pipeline.py` | 更新与当前代码不符的 dense-only 说明，补回并更新可独立复现的训练流程测试。 |

原有用户修改，包括 padding/causal mask、MoE 双路训练、Token Mixing 和 Chunk Tokenizer 变更，均保留并随本次版本提交。
